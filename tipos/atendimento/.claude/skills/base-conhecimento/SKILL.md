# Base de conhecimento

## Artigo
- Título com a pergunta ou a tarefa do cliente ("Como emitir a segunda via do boleto?").
- Resposta direta no primeiro parágrafo; passo a passo numerado; uma tarefa por artigo.
- Palavras do cliente, não do sistema interno.
- Termine com como falar com um atendente.
- `revisado_em` atualizado sempre que mexer; artigo com mais de 6 meses entra na revisão.

## Macro
Saudação → reconhecimento do problema → resposta → próximo passo → fechamento. Personalize com variáveis (`{{nome}}`, `{{protocolo}}`), nunca com dados fixos.

## Políticas
Prazos, valores e regras só de `docs/politicas.md`. Na dúvida, pergunte ao Operador.

## Dados
Exemplos sempre fictícios. Nunca copie texto de ticket com nome, CPF, e-mail, telefone, endereço ou número de pedido real.
