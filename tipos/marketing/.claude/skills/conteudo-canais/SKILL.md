# Conteúdo por canal

| Canal | Limite conferido pelo validador | Boas práticas |
|-------|---------------------------------|---------------|
| `x` | texto até 280 caracteres | uma ideia, gancho na primeira linha |
| `linkedin` | texto até 3.000 | primeiras 2 linhas decidem o "ver mais"; até 3 hashtags |
| `instagram` | legenda até 2.200; até 30 hashtags | texto na arte curto; CTA na legenda |
| `facebook` | texto até 5.000 | |
| `tiktok` | legenda até 2.200 | roteiro com gancho nos 3 primeiros segundos |
| `youtube` | descrição até 5.000 | |
| `email` | `assunto` até 60, `pre_header` até 100 | um CTA principal; descadastro obrigatório |
| `blog` | `titulo_seo` até 60, `meta_descricao` até 160 | H2 a cada 300 palavras; links internos |
| `google-ads` | `titulos` até 30 cada (máx. 15), `descricoes` até 90 cada (máx. 4) | palavra-chave no título |
| `meta-ads` | texto principal até 2.200 | primeiras 125 caracteres aparecem sem cortar |
| `whatsapp` | mensagem até 1.024 | só para quem optou por receber |

## UTMs
`url` de toda peça leva `utm_source` (canal), `utm_medium` (social, email, cpc, organic) e `utm_campaign` (`<NNN>-<slug>`). `utm_content` diferencia peças do mesmo canal.
